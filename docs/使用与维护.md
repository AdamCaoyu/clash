# 使用与维护

## 现有 OpenClash 入口

沿用已有订阅、转换服务和自定义模板地址 `https://raw.githubusercontent.com/AdamCaoyu/clash/refs/heads/main/Clash-Full.ini`。本次不更换转换服务，不修改路由器运行配置、DNS 或账户设置。

## 更新与选择节点

1. 备份当前运行 YAML，再在原“配置订阅”入口更新。该操作可能重载 OpenClash。
2. 原有 32 个组均保留。检查面板是否保留你的旧选择；配置文件无法保证缓存选择不丢失。日常服务仍可选择“所有-自动”、地区自动组或组合自动组。
3. 对 ChatGPT、Claude、Google、GitHub、Microsoft、Amazon、PayPal 等重要账号，在各自服务组内直接点选一个已经验证可用的具体节点。各组独立，不必先改共享的“所有-手动”。不需要固定的服务继续用自动组选项。
4. Apple Intelligence 默认跟随 ChatGPT。OneDrive 恢复原来的“美国-自动”；新增“🔑 微软登录”默认跟随 OneDrive。更新后核对这两个选择，缓存可能保留旧版本的 Microsoft 选项。登录组包含共用身份资源，也会影响其他使用相同域名的微软应用，详见 [OneDrive 排查](OneDrive排查记录.md)。
5. “🌍 国外”保留原默认 DIRECT；按你的原使用习惯选自动或手动出口。最终未匹配流量固定 `MATCH,DIRECT`，不会随“国外”组改变。
6. Netflix 保留原独立分组，可选择“新加坡-自动”等原有选项；不强制改地区或改手动。

新增 ChatGPT / Claude 初始跟随 AI1，Google 跟随国外组，PayPal 默认 DIRECT，不自动猜测哪个地区或节点适合你的账号。固定登录出口后不要再把该组指回测速组。服务端出口 IP 仍可能由节点商更换；订阅删除或重命名节点也可能使选择失效，更新后需复核。不能保证任何配置免于账号风控。

## 自动组

保留原有 10 个 url-test 组、180 秒检测周期和 100 ms 切换容差。自动选择根据测试地址的延迟与存活状态判断，不等于对应网站一定解锁或可登录。参数说明见 [Mihomo url-test](https://wiki.metacubex.one/config/proxy-groups/url-test/)。

修正组合地区组误含“广美”、美国 US 匹配到 RUS，以及其他地区的单字误匹配。无匹配节点的组使用 REJECT，避免转换器自动填 DIRECT。自动组含有 REJECT 是空组保护，不是可用节点。

## 规则顺序

局域网 → Apple AI / ChatGPT → 个人例外 → 精确业务及 CDN 例外 → 独立业务与账号 → 其他 AI → 普通 Apple → 游戏 → Netflix IP / Amazon 云平台 → 国外集合 → DIRECT。

Google 通用 CDN 例外先于 YouTube，YouTube 先于 Google；GitHub Copilot 归 GitHub，Google AI 与登录归 Google；微软登录和 OneDrive 补充先于 OneDrive 基础列表，再到 Microsoft，Bing / Copilot 归 Microsoft；这些专项规则都先于宽泛 AI1。原 AI2 仍负责 Meta AI 和 Perplexity。普通 Apple 与 Apple AI 分开，不把整个 iCloud 或 App Store 当成 AI 代理。

共享第三方登录、验证码、支付域名不能仅凭域名准确区分所属账号。不把整个 auth0.com、stripe.com、sentry.io、trafficmanager.net 强行塞入某个 AI / OneDrive 组；实际仍有错误时，应根据连接日志补精确地址。

## 规则更新

现场“使用规则集”关闭：规则静态展开到 YAML，上游变化需要更新订阅。若希望规则定时刷新，可使用你现有订阅编辑页的“使用规则集”，后端需支持 `expand=false&classic=true`。

原生来源使用 clash-classic / clash-domain，刷新间隔 86400 秒。它是定时更新，不是实时推送；节点订阅更新仍由原订阅功能管理。后端不兼容时保持静态模式。不要额外叠加另一整套规则覆盖业务顺序。

## 维护与回滚

修改 `config/openclash.ini`、个人 `list/` 后运行 `python3 scripts/sync_templates.py` 和 `python3 -m unittest discover -s tests -v`。真实转换结果再用 `scripts/validate_generated.py` 及 Mihomo `-t` 验证。

路由器需要回滚时恢复备份 YAML。GitHub 使用 git revert 保留历史。私人 YAML、订阅和节点信息放本地 `.local/`，不上传。

## 这次全量复查修正

Amazon 包含 AWS / CloudFront 泛规则，已后移到具体媒体、支付、游戏之后。Disney / Netflix / HBO 改用 MetaCubeX 服务域名源，另保留已知专用 CDN 补充，不再把整个 AWS 区域分给某个媒体组。Netflix 独立 IP 列表补回原普通 YAML 没有的 IP 路由。

Apple 下载 CDN、Google 离线地图 / 更新资源及部分 AI 域名增加精确前置规则，防止被 Microsoft、YouTube、TikTok 的宽规则抢占。blackmatrix7 含 IP 的来源改用 No_Resolve 版本，尤其 LAN 不再为了匹配 IP 先触发 DNS。

通用云平台地址未必能判断具体业务归属；没有明确服务规则时仍按后面的通用规则处理。这不是全互联网流量的归属保证，后续以实际连接日志修正。
